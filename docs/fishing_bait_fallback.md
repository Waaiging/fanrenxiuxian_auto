# 灵溪垂钓鱼饵降级

开竿优先使用 Dashboard 配置的鱼饵。配置同时是开竿用饵的等级上限；库存、
可购买数量、鱼塘推荐和商店返回顺序都不能让程序自动选用更高级的鱼饵。

降级顺序：月华饵 → 妖血饵 → 灵虫饵 → 灵米饵 → 凡饵。
例如配置妖血饵时，材料不足、未解锁或商店已无该鱼饵，就依次尝试
灵虫饵、灵米饵、凡饵；每档本轮最多尝试一次，有库存则直接使用。
最近一档只买得起 1 份时，仍先选它。所有低档都不可用时停止本轮，
材料不足继续使用既有的一小时资源等待排程，不购买或消耗月华饵。

网络超时、限流、授权刷新、价格数据缺失，以及未确认到账的购买结果，
交回既有错误处理，不因这些情况继续购买其他鱼饵。

降级不会改写设置；下一竿重新检查配置鱼饵，有库存或材料恢复后优先使用。
状态分别记录配置鱼饵、实际鱼饵和 `fallback` 选择原因，购买汇总只计入
已确认到账的购买。完整账号与受限待机共用同一实现。

回归测试：`tests/test_miniapp_fishing_bait_fallback.py`，另有
`tests/test_miniapp_fishing.py` 的开竿流程测试。
